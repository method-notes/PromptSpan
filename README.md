# PromptSpan

Anonymous project website for **PromptSpan: Prompt-Aware Performance Modeling for LLM Serving**.

- Website: https://method-notes.github.io/PromptSpan/
- Anonymous code and processed data: https://anonymous.4open.science/r/PromptSpan-42B4

This repository contains the static website, current paper figures, and the verified main-method results CSV. It does not contain the paper PDF, raw prompts, credentials, or private author information.

The reproducibility artifact covers the PromptSpan main-method rows, not baseline or ablation implementations. The website's relative asset paths support GitHub Pages project-site hosting.

GitHub Pages publishes the repository root. No build step, analytics, external font services, or package installation is needed.
