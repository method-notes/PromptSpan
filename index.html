AT A GLANCE

Beyond request rate.

Requests arriving at the same rate can still place very different demands on an LLM serving system. PromptSpan brings prompt information into latency prediction—and adapts its contribution as serving pressure changes.

The method combines Adaptive Residual Correction (ARC) with Meta-Transfer Calibration (MTC). It predicts time-window mean, P50, and P95 latency at GPU replica counts unseen during training, using a correction head trained on single-GPU data.

01 / MOTIVATION

Why prompts matter.

Request intensity is only part of the workload story.

01

Similar QPS. Different latency.

At similar request rates, prompt-derived groups show different latencies and different residual errors in a QPS-based model. Prompt features provide an additional predictive signal beyond workload intensity.

02

The correction depends on pressure.

Prompt-related residual differences vary with serving pressure. This motivates a pressure-conditioned gain: the same prompt signal should not receive a fixed correction weight in every workload condition.

These findings are predictive associations in a controlled-replay benchmark with reconstructed prompts, not an isolated causal effect of prompt semantics.

02 / METHOD

Two components. One prediction pathway.

Prompt-aware correction, trained to transfer across pressure domains.

ARCAdaptive Residual Correction

Use prompts where they help.

ARC calibrates a prompt-aware request predictor using workload context and the contrast between matched prompt-aware and QPS-based predictions. A learned gain conditions the contrast correction on per-replica QPS and input-token rate.

Δ = C(u) + g(ρ)(P − N)context calibration + adaptive contrast correction
MTCMeta-Transfer Calibration

Learn to handle unseen replica counts.

MTC trains only the compact correction head across pressure domains constructed from single-GPU training data. Support/query updates across pressure levels encourage transfer without multi-GPU training labels or target adaptation.

PREDICTION TARGET

Corrected request-level predictions are aggregated into non-overlapping five-second windows to estimate mean, P50, and P95 latency.

RQ1 / BASELINE COMPARISON

7.40% average MAPE.

PromptSpan reduces P50–P95 average MAPE by 62.38% relative to LLM-Pilot, the strongest task-adapted baseline. It has lower error than all four baselines in every one of the 18 evaluated model–load–replica combinations.

The comparison uses task-adapted local surrogates under a shared evaluation protocol, rather than direct runs of each original serving system.
